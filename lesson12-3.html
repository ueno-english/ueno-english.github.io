Lesson 12-3 文法解説

仮定法過去（もし〜だったら、…なのに）
🌟 直説法 vs 仮定法 💡 仮定法過去 ✨ I wish / as if ✏ 練習の答え
🌟 Key Point 1　直説法 vs 仮定法　― if の「距離感」
💡 if は「現実に近い話」か「現実離れした話」かで使い分ける！

if（もし）という接続詞は、動詞の形を変えるだけで「本当に起こりそうな話」か「まず起こらない・現実と違う話」かを表現できます。

直説法（実際に起こりうる）仮定法（まず起こらない・現実と異なる）
if節：現在形
主節：will ＋ 動詞原形		 if節：過去形
主節：would / could ＋ 動詞原形
If it rains this weekend,
we will cancel the barbecue.
今週末雨が降れば、バーベキューを中止するでしょう。
（実際に降るかも）		 If I had more money,
I could buy the new game.
もっとお金があれば、ゲームが買えるのに。
（現実にはお金がない）
⚠️ 「現在形か過去形か」で意味が変わる！
直説法 If it rains → 「実際に雨が降るかも」（天気予報的な話）
仮定法 If it rained → 「雨が降ったらいいのに / 降ることはないが…」（現実とは違う話）
💡 Key Point 2　仮定法過去　If ＋ 過去形, would / could ＋ 動詞原形
📌 現実とは異なることを仮定する！

「今〜だったら…なのに」と現実とは違うことを想像するときに使います。

📚 仮定法過去の作り方
If ＋ 主語 ＋ 動詞の過去形 ,  主語 ＋ would / could / might ＋ 動詞原形 .
▶ if節（仮定）：動詞を過去形にする
▶ 主節（想像の結果）：would / could / might ＋ 動詞原形
助動詞の変化：will → would　／　can → could　／　may → might
（現実）I don't have enough time. → I can't stay longer.
⇓ 仮定法で「もし〜なら」と想像する
If I had enough time, I would stay for another month.
「もし十分な時間があれば、もう1か月滞在するのに。」（実際には時間がない）
⚠️ be動詞は主語に関係なく「were」！
✕ If I was you, ...（×　誤り！）
✓ If I were you, I wouldn't give up now.（◯ 正しい！）
✓ If she were here, she could help us.（I・he・she でも were！）
📚 教科書の例文を確認しよう

"If I were you, I wouldn't give up now."

「もし私があなたなら、今あきらめないのに。」（現実は私ではない）

"If I weren't so busy, I could hang out with you."

「そんなに忙しくなければ、一緒に遊べるのに。」（現実は忙しい）

✨ Key Point 3　I wish ／ as if（as though）＋ 仮定法
★ I wish ＋ 主語 ＋ 過去形　―「〜ならよいのに」

現在実現していない願望を表します。「現実は違うけど、〜だったらいいのに」というニュアンス。

I wish ＋ 主語 ＋ 動詞の過去形　（be動詞は were）

"I wish I didn't have so much homework."

「こんなに宿題がなければいいのに。」（実際にはたくさんある）

"I wish I could sing like the star."

「あのスターのように歌えたらいいのに。」（実際にはそう歌えない）

★ as if / as though ＋ 主語 ＋ 過去形　―「まるで〜のように」

事実とは異なることに比べて、「まるで〜のようだ」と言うときに使います。

動詞 ＋ as if / as though ＋ 主語 ＋ 動詞の過去形　（be動詞は were）

"He acts as if he were the best player on the team."

「彼はまるでチームで一番うまい選手のようにふるまいます。」（実際はそうではない）

"He talks as if there were no problem."

「まるで問題など何もないかのように話す。」（There is / are の仮定法 → There were）

⚠️ I wish / as if の後の be動詞もすべて were！
✕ I wish I was taller.（× 誤り）
✓ I wish I were taller.（◯ 正しい）
✏️ 練習問題の答え
練習１（①〜⑤）　直説法・仮定法過去
① もし明日雨が降れば、バスで学校に行くでしょう。
If it rains tomorrow, I will go to school by bus.
直説法（実際に雨が降るかも）
If it rains tomorrow, I will go to school by bus.
▶ 直説法：if節は現在形（rains）、主節は will + 動詞原形（will go）
② もし翼があれば、学校まで飛んで行けるのに。
If I had wings, I would fly to school.
仮定法過去（現実には翼がない）
If I had wings, I would fly to school.
▶ 仮定法過去：if節は過去形（had）、主節は would + 動詞原形（would fly）
③ もし忙しくなければ、あなたを手伝えるのに。
If I were not busy, I would help you.
仮定法過去（be動詞は were！）
If I were not busy, I would help you.
▶ 仮定法のbe動詞はすべて were！I でも were を使う
④ もしジョンがチームにいれば、トーナメントで勝てるのに。
If John were on the team, we could win the tournament.
仮定法過去（be動詞は were）
If John were on the team, we could win the tournament.
▶ John（3人称単数）でも仮定法 → were。主節は could（can の過去形）+ win
⑤ もしスマートフォンを持っていれば、ジョンにメッセージを送れるのに。
If I had my smartphone with me, I could send text messages to John.
仮定法過去
If I had my smartphone with me, I could send text messages to John.
▶ if節：had（have の過去形）、主節：could send（can + send の仮定法形）
練習２（⑥〜⑧）　仮定法過去・I wish・as if
⑥ もし10歳年上だったら、何をしたいですか。
What would you like to do if you were ten years older?
仮定法過去（疑問文）
What would you like to do if you were ten years older?
▶ 疑問文で仮定法：What would ～ if ～ were？主節が疑問文の形になる
⑦ そのミュージカルは素晴らしかった！あのスターのように歌えたらいいのに！
The musical was amazing! I wish I could sing like the star!
I wish ＋ 仮定法
The musical was amazing! I wish I could sing like the star!
▶ I wish ＋ 仮定法：could（can の過去形）＋ sing。「実際にはそう歌えない」という現実と反する願望
⑧ メアリーの兄はまるで映画スターのようにふるまいます。
Mary's brother behaves as if he were a movie star.
as if ＋ 仮定法
Mary's brother behaves as if he were a movie star.
▶ as if ＋ 仮定法：he でも were を使う。「まるで映画スターのようにふるまう」（実際はそうではない）
