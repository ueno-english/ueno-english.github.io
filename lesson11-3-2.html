Lesson 11-3② 補足解説

🔁 so ～ that …（言い換えを完全マスター）
📌 Key Point ✏️ 練習①〜③ 🔄 練習④〜⑥ 🎯 クイズ ← 11-3①へ
🔁 Key Point　so ～ that …（とても〜なので…できない）
📐 公式をおさらい
so ＋ 形容詞・副詞 ＋ that S can't V とても〜なので S は…できない
so ＋ 形容詞・副詞 ＋ that S can V とても〜なので S は…できる
too ＋ 形容詞 ＋ to V　↕ 言い換え可 so ＋ 形容詞 ＋ that S can't V
🔄 言い換え例
This tea is too hot to drink.
↕ 同じ意味！
This tea is so hot that I can't drink it.
→「このお茶はとても熱いので、私は飲めません。」

熱すぎて飲めない　＝　とても熱いので飲めない

⚠️ that の後は必ず〈S ＋ can't / couldn't ＋ V〉の形！
too ～ to V → 主語なし（シンプル）
so ～ that S can't V → that の後に 主語 ＋ can't が必要！
練習１　so ～ that の穴埋め（①〜③）
① この紅茶はとても熱いので私には飲めません。
This tea is (　　) (　　) that I (　　) (　　) it.
This tea is so hot that I can't drink it.
▶ so hot that I can't drink = とても熱いので飲めない
② 交通がとても混んでいたので、授業に間に合えませんでした。
The traffic was (　　) (　　) that I (　　) be in time for the (　　).
The traffic was so busy that I couldn't be in time for the class.
▶ so busy that I couldn't = とても混んでいたので間に合えなかった
③ その宿題はとても難しかったので彼女には1日では終わらせられませんでした。
The homework was (　　) (　　) that she (　　) (　　) it in a day.
The homework was so difficult that she couldn't finish it in a day.
▶ so difficult that she couldn't finish = 難しすぎて1日では終わらせられなかった
練習２　too ～ to V → so ～ that に書き換え（④〜⑥）
④
This is too large for me to carry on my back.
→ This is (　　) (　　) that I (　　) (　　) it on my back.
→ This is so large that I can't carry it on my back.
▶ too large for me to carry → so large that I can't carry it
※ too ～ to V では目的語（it）が不要だが、so ～ that では that 節の中に it が必要！
⑤
Betty was too shy to talk to the teacher.
→ Betty was (　　) (　　) that she (　　) (　　) to the teacher.
→ Betty was so shy that she couldn't talk to the teacher.
▶ too shy to talk → so shy that she couldn't talk
※「ベティ」が主語なので she を使う
⑥
The teacher spoke too fast for me to understand.
→ The teacher spoke (　　) (　　) that I (　　) (　　).
→ The teacher spoke so fast that I couldn't understand.
▶ too fast for me to understand → so fast that I couldn't understand
※ understand は自動詞として使われているので目的語なしでOK
