確認問題（教科書 p.85）
1　●現在完了進行形の形と意味●　次の英文を日本語に直す
  1. My father has been a math teacher since 2000.
  2. We have been cooking in the kitchen for an [one] hour.
  3. I have had an old Japanese doll for ten years.
  4. The girl has been taking care of the dog since last night.
  1. わたしの父は2000年からずっと数学教師です。💡 be（状態動詞）は現在完了（継続）で表し、進行形にはしない。has been。
  2. わたしたちは1時間ずっと台所で料理をしています。💡 cook（動作動詞）はhave been ～ing（現在完了進行形）で「ずっと〜し続けている」。
  3. わたしは10年間ずっと古い日本人形を持っています。💡 have（持っている、状態動詞）は進行形にしない。have had（現在完了）で表す。
  4. その少女は昨夜からずっとその犬の世話をしています。
2　●状態動詞と動作動詞●　次の動詞を日本語に直し、状態を表す動詞であればア、動作を表す動詞であればイを書く
  1. (1) read　(2) know　(3) be　(4) dance　(5) write　(6) make　(7) live　(8) like　(9) run　(10) want
  1. (1) 読む：イ　(2) 知っている：ア　(3) …である、いる：ア　(4) 踊る：イ　(5) 書く：イ
  2. (6) 作る：イ　(7) 住んでいる：ア　(8) 好きである：ア　(9) 走る：イ　(10) ほしい：ア💡 know・be・live・like・wantのような「気持ちや状態」を表す動詞は進行形にしない。read・dance・write・make・runは「動作」を表す動詞。
3　●否定文、疑問文、疑問詞を用いた疑問文●　次の文を、〔　〕内の指示に従って書きかえる
  1. Mary has been talking with her mother for ten minutes.〔否定文に〕
  2. Those boys have been swimming in the sea for two hours.〔否定文に〕
  3. Kent has been using his dictionary since this morning.〔疑問文に〕
  4. Ben and Jun have been doing their homework for an hour.〔疑問文に〕
  5. Jack has been playing the game in his room.〔下線部が答えの中心となる疑問文に〕
  6. They have been practicing kendo for two hours.〔下線部が答えの中心となる疑問文に〕
  1. Mary hasn't [has not] been talking with her mother for ten minutes.
  2. Those boys haven't [have not] been swimming in the sea for two hours.
  3. Has Kent been using his dictionary since this morning?
  4. Have Ben and Jun been doing their homework for an hour?
  5. Where has Jack been playing the game?💡 場所をたずねるのでWhere。
  6. How long have they been practicing kendo?💡 期間をたずねるのでHow long。
練成問題（教科書 p.86-87）
1　次の（　）に入る最も適当な語（句）をあとから選び、記号で答える
  1. I（ア know　イ knew　ウ knowing　エ have known）Tom since we were students.
  2. That girl has been（ア dance　イ dances　ウ danced　エ dancing）over there for one hour.
  3. We（ア are　イ been　ウ have been　エ have being）good friends for a long time.
  4. Have you（ア watching　イ watches　ウ been watched　エ been watching）the movie for three hours?
  5. Judy hasn't（ア looks　イ looking　ウ been looking　エ been looked）for the cat for a long time.
  1. エ（have known）💡 since（起点）があるので現在完了。knowは状態動詞なので進行形にしない。
  2. エ（dancing）💡 has been ___ing（現在完了進行形）。danceは動作動詞。
  3. ウ（have been）💡 for a long time（期間）があるので現在完了。be動詞の過去分詞はbeen。
  4. エ（been watching）💡 Have you been ___ing（現在完了進行形の疑問文）。
  5. ウ（been looking）💡 look for「探す」は動作動詞なので進行形にできる。hasn't been ___ing。
2　次の日本文に合う英文になるように＿に適する語を書く
  1. わたしは9時からここにいます。 I ___ ___ here ___ nine o'clock.
  2. この前の水曜日からずっととても寒いです。 It ___ ___ very cold ___ last Wednesday.
  3. 1週間ずっと雨が降っています。 It ___ ___ ___ a week.
  4. ジムは1時間ずっとその問題について考えています。 Jim ___ ___ ___ about the problem ___ one hour.
  5. わたしの妹は2時間前からずっとフランス語を勉強しています。 My sister ___ ___ ___ French ___ two hours.
  6. あなたはけさからずっとそのCDを聞いているのですか。 ___ you ___ ___ to the CD ___ this morning?
  7. わたしたちは長い間の知り合いというわけではありません。 We ___ ___ each other ___ a long time.
  8. あなたはいつから星を見ているのですか。 How long ___ you ___ ___ at the stars?
  1. have been, since💡 beは状態動詞なので進行形にせずhave been。
  2. has been, since
  3. has been raining for💡 rainは動作動詞なので現在完了進行形has been raining。
  4. has been thinking, for
  5. has been studying, for
  6. Have, been listening, since
  7. haven't known, for💡 knowは状態動詞なので進行形にせずhaven't known。
  8. have, been looking
3　次の英文を日本語に直す
  1. We have been very busy since last month.
  2. I have been washing the dishes for thirty minutes.
  3. Has that baby been crying for a long time?
  1. わたしたちは先月からずっととても忙しい。
  2. わたしは30分間ずっと皿を洗っています。
  3. あの赤ん坊は長い間ずっと泣いているのですか。
4　次の文を、〔　〕内の指示に従って書きかえる
  1. Judy has been talking on the phone for fifteen minutes.〔否定文に〕
  2. That boy has been studying in the library since ten o'clock.〔疑問文に書きかえ、yesで答える〕
  3. Ms. Sato has been practicing the piano for two hours.〔下線部が答えの中心となる疑問文に〕
  1. Judy hasn't [has not] been talking on the phone for fifteen minutes.
  2. Has that boy been studying in the library since ten o'clock? — Yes, he has.
  3. How long has Ms. Sato been practicing the piano?
5　日本文に合う英文になるように（　）内の語句を並べかえる
  1. わたしたちは3週間ずっと北海道にいます。（have / Hokkaido / we / for / in / three weeks / been）.
  2. 彼は昨夜からずっとそのコンピュータを使っています。（using / since / the computer / has / last night / he / been）.
  3. わたしは2010年から福岡で暮らしています。（Fukuoka / in / 2010 / lived / since / have / I）.
  4. あの男性は1時間以上ずっと話しています。（been / for / speaking / more / an hour / that man / than / has）.
  5. あなたは去年から自転車を買いたいと思っているのですか。（wanted / since / have / last year / to / a bike / buy / you）?
  6. いつから雪が降っているのですか。（long / it / snowing / how / been / has）?
  1. We have been in Hokkaido for three weeks.
  2. He has been using the computer since last night.
  3. I have lived in Fukuoka since 2010.💡 liveは状態動詞なので進行形にせずhave lived。
  4. That man has been speaking for more than an hour.
  5. Have you wanted to buy a bike since last year?💡 wantは状態動詞なので進行形にせずhave wanted。
  6. How long has it been snowing?
6　次の日本文を英語に直す
  1. わたしたちは20分間ずっとバスを待っています。
  2. 彼女は正午からずっとカギを探しています。
  3. 彼らは午前6時からずっとその部屋をそうじしています。
  4. あなたはそのときからずっとサッカーが好きなのですか。
  5. あの犬はいつからいすの上で眠っているのですか。
  1. We have been waiting for the [a] bus for twenty minutes.
  2. She has been looking for the [her / a] key since noon.
  3. They have been cleaning the room since six (o'clock) in the morning.
  4. Have you liked soccer since then [that time]?💡 likeは状態動詞なので進行形にせずhave liked。
  5. How long has that dog been sleeping on the chair?
