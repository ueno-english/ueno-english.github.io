Sirius Unit 2 助動詞

💡 Key Point 1　助動詞の種類と意味
📚 助動詞のあとの動詞は必ず「原形」！

助動詞は動詞に意味を付け加える言葉。主語が3人称単数でも s はつけない。

助動詞意味
can（could）〜できる、〜してもよい〔能力・許可〕
may〜してもよろしい、〜かもしれない〔許可・推量〕
must〜しなければならない、〜にちがいない〔義務・推量〕
should〜すべきだ〔義務・助言〕
He can speak Chinese.
彼は中国語が話せます。（能力）
You may go now.
もう行ってもよいですよ。（許可）
It may be snowy tomorrow.
明日は雪かもしれません。（推量）
⚠️ 短縮形
cannot → can't　／　could not → couldn't
must not → mustn't　／　should not → shouldn't
❌ Key Point 2　否定文〈主語＋助動詞＋not＋動詞の原形〉
主語 ＋ 助動詞 ＋ not ＋ 動詞の原形 〜.
You should not go to the party.
あなたはパーティーに行くべきではありません。
You must not watch TV so long.
そんなに長くテレビを見てはいけません。〔してはいけない＝禁止〕
⚠️ must not と don't have to はまったく違う意味！
must not（‏mustn't）→ 「してはいけない」〔禁止〕
don't have to → 「する必要がない」〔不要〕　※Key Point 4 でくわしく
❓ Key Point 3　疑問文〈助動詞＋主語＋動詞の原形 〜?〉
助動詞 ＋ 主語 ＋ 動詞の原形 〜?
答え方：Yes, 主語 ＋ 助動詞. / No, 主語 ＋ 助動詞 ＋ not.
Should の疑問文
Should he go to the party?
彼はパーティーに行くべきですか。
— Yes, he should. / No, he should not.
Must の疑問文と答え方に注意！
Must I come home early today?
今日は早く帰らなければなりませんか。
— Yes, you must.　／　— No, you don't have to.

※ Must の疑問文に「不要」と答えるときは don't have to を使う（No, you mustn't. だと「禁止」の意味になってしまう）。

🔄 Key Point 4　助動詞のはたらきをする語句
📌 can・must には「過去形」「未来形」がない → 言いかえが必要
助動詞言いかえ例
can（〜できる）be able toTaro is able to run fast.
must（〜しなければならない）have toWe have to help each other.
should（〜すべきだ）had betterMy father says I had better read a lot of books.
過去と未来の言い方
be able to　→；　過去 was / were able to　／　未来 will be able to
have to　→；　過去 had to　／　未来 will have to
The old man is able to ride a bike.
→　(過去) The old man was able to ride a bike.
He has to go to the bookstore.
→　(疑問) Does he have to go to the bookstore?
⚠️ had better は「should」より強い忠告
You had better not watch TV so long. のように、否定は had better not ＋ 動詞の原形。
💬 Key Point 5　助動詞を含む慣用表現
表現意味
Can / Will / Could / Would you (please) 〜?〜してくれますか（依頼）
Shall we[I] 〜?（いっしょに）〜しましょうか／〜しましょうか
Would you like …?…はいかがですか（すすめる）
Will you bring me some water?
お水を持ってきてくれますか。
Shall we go fishing next Sunday?
今度の日曜日に釣りに行きませんか。
Would you like some tea?
紅茶はいかがですか。
答え方のバリエーション

Sure. / Of course. / OK. / All right.（承諾）
(I'm) Sorry, (but) I can't.（断る）
That's (not) a good idea.（Shall I 〜? への賛成・反対）
Yes, let's. / No, let's not.（Shall we への答え）
(Yes,) Thank you. / Yes, please. / No, thank you.（すすめられて）
