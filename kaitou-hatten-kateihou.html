確認問題（教科書 p.169）
1　●直説法と仮定法●　次の英文を、下線部に注意して日本語に直す
  1. If you are not busy, please help me.
  2. If you had a brother, what would you like to do with him?
  3. If I were this man, I would run away.
  4. If I didn't have a lot of homework, I could go fishing with you.
  1. もしあなたが忙しくなければ、わたしを手伝ってください。💡 現在形（are）は「本当にそうかもしれない」直説法。仮定法ではない。
  2. もしあなたにお兄[弟]さんがいれば、あなたは彼と何をしたいですか。💡 had（過去形）＋ would。「実際にはいない」ことを表す仮定法過去。
  3. もしわたしがこの男なら、逃げるでしょう。💡 If I were 〜, I would 〜。be動詞はwere。
  4. もしわたしにたくさん宿題がなければ、あなたといっしょに魚つりに行けるのですが。💡 「実際は宿題がたくさんあるので行けない」という現在の事実と反対のことを表す。
2　●仮定法過去●　次の各問いに答える
  1. (1) 次の（　）に入る最も適当な語をア〜エから選ぶ。 ① If he had enough money, he（　）buy that car. ア can イ could ウ will エ may　② If they（　）not sick, they would visit us. ア are イ were ウ have エ been
  2. (2) 次の文をあとの日本文に合う文に書きかえる。 As I am not free, I cannot read this book.（もしわたしがひまなら、この本を読むことができるのですが。）
  1. ① イ　② イ💡 ① If 〜 had（過去形）のとき、主節は助動詞の過去形（could）。② If 〜 were not（過去形）。
  2. If I were [was] free, I could read this book.💡 「ひまではない」現実を、If I were free（仮定法過去）、could read で表す。くだけた会話では was も使われる。
3　●仮定法過去完了●　次の各問いに答える
  1. (1) 次の（　）に入る最も適当な語（句）をア〜エから選ぶ。 ① If we had been free, I（　）have gone shopping. ア can イ could ウ will エ may　② If he（　）with me, he would have helped me. ア am イ are ウ has been エ had been
  2. (2) 次の文をあとの日本文に合う文に書きかえる。 I couldn't see Mary because I was late.（もしわたしが遅れていなかったら、メアリーに会えたのですが。）
  1. ① イ　② エ💡 仮定法過去完了は《If＋主語＋had＋過去分詞…, 主語＋助動詞の過去形＋have＋過去分詞〜》。
  2. If I hadn't [had not] been late, I could have seen Mary.💡 「遅れた」→「遅れていなかったら」＝ If I had not been late。
4　●I wish ～.の文●　次の日本文に合う英文になるように＿に適する語を書く
  1. わたしがお金持ちならいいのに。 I ___ I ___ rich.
  2. わたしが家にいればよかったのにと思います。 I wish I ___ ___ at home.
  1. wish, were [was]💡 現在の事実と反対の願望は《I wish＋主語＋過去形》。
  2. had been💡 過去の事実と反対の願望は《I wish＋主語＋had＋過去分詞》。
練成問題（教科書 p.170-171）
1　次の英文を日本語に直す
  1. Let's go swimming if it is sunny next Sunday.
  2. If we were not busy, we would go to see you.
  3. If we had not been busy, we would have gone to see you.
  4. I wish I lived in France.
  5. I wish I had lived in France.
  1. もし次の日曜日晴れたら、泳ぎに行きましょう。💡 if節の中の現在形は直説法（実際に起こるかもしれないこと）。
  2. もしわたしたちが忙しくなければ、あなたに会いに行くのですが。💡 仮定法過去。「今は忙しいので行けない」。
  3. もしわたしたちが忙しくなかったら、あなたに会いに行ったのですが。💡 仮定法過去完了。「あのとき忙しかったので行けなかった」。
  4. わたしがフランスに住んでいればいいのに。💡 I wish＋過去形＝現在の願望。
  5. わたしがフランスに住んでいたらよかったのに。💡 I wish＋had＋過去分詞＝過去についての願望。
2　次の（　）に入る最も適当な語（句）を、それぞれ1つずつ選ぶ
  1. If you visit your aunt, she（　）very happy. ア is イ was ウ will be エ has been
  2. If there were no water on the earth, we（　）not live. ア can イ will ウ may エ could
  3. I wish my grandfather（　）here with me now. ア be イ is ウ were エ has been
  4. If I had been with you, I（　）things like those. ア didn't do イ haven't done ウ won't do エ wouldn't have done
  1. ウ💡 visit（現在形）は直説法。主節は未来のwill be。
  2. エ💡 If there were（過去形）なので、主節は could。
  3. ウ💡 I wish ＋ 主語 ＋ were（過去形）。
  4. エ💡 had been（過去完了）なので、主節は wouldn't have done。
3　次の日本文に合う英文になるように＿に適する語を書く
  1. 疲れているなら、あなたは今夜早く寝るべきです。 ___ you ___ ___, you should go to bed early tonight.
  2. あした雨が降ったら、一日中家にいましょう。 Let's stay home all day ___ ___ ___ tomorrow.
  3. もしわたしが道を知っていれば、あなたをそこへ連れていくことができるのに。 ___ I ___ the way, I ___ ___ you there.
  4. もしもっと若かったら、あなたは何をしたいですか。 If you ___ ___, what ___ you like to do?
  5. もし携帯電話をなくさなかったら、わたしはあなたに会えたでしょう。 If I ___ ___ my cell phone, I ___ ___ seen you.
  6. 中国語を話せたらいいのになあ。 I ___ I ___ speak Chinese.
  7. あなたにわたしの家への道順を話しておけばよかったです。 I wish I ___ ___ ___ the way to my house.
  1. If, are tired💡 「疲れているなら」は現実にありうる条件＝直説法（現在形）。
  2. if it's rainy または if it rains💡 未来のことでも if節の中は現在形。
  3. If, knew, could take💡 現在の事実と反対＝仮定法過去。
  4. were younger, would💡 If you were younger, what would you like to do?
  5. hadn't lost, could have💡 過去の事実と反対＝仮定法過去完了。
  6. wish, could💡 I wish I could 〜「〜できたらいいのに」。
  7. had told you💡 過去についての願望。told you the way「あなたに道順を話す」。
4　次の各組の文がほぼ同じ内容になるように＿に適する語を書く
  1. (1) a I can't buy this bag because I don't have enough money. b ___ I ___ enough money, I ___ ___ this bag.
  2. (2) a Take the first train, and you will get to the airport before 7:00. b ___ you ___ the first train, you will get to the airport before 7:00.
  3. (3) a I'm sorry I can't help you now. b I ___ I ___ ___ you now.
  4. (4) a I was late for school because I didn't take the train. b If I had taken the train, I ___ ___ ___ late for school.
  1. If, had, could buy💡 現在の事実（買えない）と反対＝仮定法過去。
  2. If, take💡 「〜しなさい、そうすれば…」は If you 〜, … で書きかえられる（直説法）。
  3. wish, could help💡 「助けられなくて残念」＝「助けられたらいいのに」。
  4. wouldn't have been💡 過去完了のif節 → wouldn't have been。
5　次の日本文に合う英文になるように、（　）内の語句を並べかえる
  1. もし辞書が必要なら、わたしのを使ってもいいですよ。（can / if / a dictionary / use / need / you / you /，）mine.
  2. あしたひまなら、いっしょに映画に行きませんか。（we / go / you / the movies / are / why / to / free / if / don't）tomorrow?
  3. もしわたしが大都市で暮らしていれば、車は必要ないだろうに。（lived / I / not / a car / a big city / would / need / if / in / I /，）.
  4. わたしが料理が得意だといいのですが。（were / at / wish / good / cooking / I / I）.
  5. あなたといっしょにそのコンサートに行けばよかった。（the concert / I / with / wish / you / gone / I / to / had）.
  6. もしわたしがそこにいたら、そのお年寄りの男性を助けていたでしょう。（have / been / the old man / I / helped / if / I / had / would）there.
  1. If you need a dictionary, you can use mine.💡 現在形のif節は直説法。
  2. Why don't we go to the movies if you are free tomorrow?💡 Why don't we 〜?「〜しませんか」。
  3. If I lived in a big city, I would not need a car.💡 仮定法過去。
  4. I wish I were good at cooking.💡 be good at 〜ing「〜が得意」。
  5. I wish I had gone to the concert with you.💡 I wish＋had＋過去分詞。
  6. I would have helped the old man if I had been there.💡 仮定法過去完了。主節 would have helped、if節 had been。
6　次の日本文を英語に直す
  1. もし彼の住所を知っているなら、教えてくれませんか。
  2. もし妹がいれば、彼女といっしょに料理をして楽しむのに。
  3. もしあなたがわたしなら、今、何ができますか。
  4. わたしが10歳若かったらいいのになあ。
  5. もし先週病気でなかったら、友達と買い物に行ったのに。
  1. If you know his address, will [can] you tell it to me?💡 「知っているなら」は現実の条件なので現在形。
  2. If I had a sister, I would enjoy cooking with her.💡 仮定法過去。
  3. If you were me, what could you do now?💡 If you were me「もしあなたがわたしなら」。
  4. I wish I were [was] ten years younger.💡 10歳若い＝ten years younger。
  5. If I hadn't [had not] been sick last week, I would have gone shopping with my friend(s).💡 last week＝過去のことなので仮定法過去完了。
